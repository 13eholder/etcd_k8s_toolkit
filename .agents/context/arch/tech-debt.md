# 已知技术债务与缺口

仓库级缺口在此汇总；专题内行为差异见对应专题文档的“待确认”。

1. **proxy 实现差异**：不同流的错误交付不一致、spawn 句柄未集中 join、日志 flush 不承诺 fsync；是否统一契约由维护者决定，见 [错误处理](../convention/error-handling.md#proxy-现有行为及缺口)。
2. **依赖许可**：依赖清单不证明依赖及其传递依赖与 Apache-2.0 兼容，发布前需审计。
3. **证据可用性**：部分历史原始实验产物按 `.gitignore` 仅本地保留；历史通过数不是当前运行证明，引用历史结论时注明其验证方式。
4. **本地资料**：`.agents/stages/`（阶段/评审归档）与 `ref/`（研究笔记）仅本地保留，不入库；文档中指向它们的链接在克隆仓库中不可达，相关结论已内联到 `.agents/context/` 各文档与本文。
